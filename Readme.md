# Projeto Habit-Treacker

Projeto front-end utilizando HTML,CSS e JavaScript, a forma da qual as tarefas são guardadas em local storage. Na página principal conciste em uma seção com as tarefas que foram criadas, um temporizador, uma outra seção onde mostra as tarefas concluidas da semana e uma barra de progresso onde toda tarefa concluida aumenta a barra semanal.
Coisas a se falar no momento o criador desta página planeja futaramente melhorar está página futuramente com backend com Node.js e armazenar as tarefas com banco de dados
